Exporting YouTube cookies (one-time setup, about 2 minutes)

  1. Install a cookies.txt exporter: cookies.txt for Firefox, or Get cookies.txt LOCALLY for Chrome. Allow it to run in private/incognito windows (in the browser's extension settings).
  2. Open a new private/incognito window and sign in to YouTube with the account that has the membership.
  3. In that same tab, go to https://www.youtube.com/robots.txt. Close any other private tabs.
  4. Click the extension's icon and export the cookies for youtube.com. This saves a cookies.txt file.
  5. Close the private window without signing out. YouTube keeps rotating cookies in open tabs, so closing it is what keeps the exported cookies valid.
  6. Click Upload cookies.txt here and choose that file.

When members-only videos start failing with a login error, repeat these steps. YouTube may restrict accounts it sees downloading, so use this sparingly.
